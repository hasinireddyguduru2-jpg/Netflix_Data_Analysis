 Netflix Data Analysis

 Project Overview
This project focuses on analyzing Netflix Movies and TV Shows dataset to understand content trends, distribution patterns, and user preferences. The goal is to extract meaningful insights using data analysis and visualization techniques.

 Objectives
- Analyze the distribution of Movies and TV Shows
- Identify top content-producing countries
- Study content growth over the years
- Explore the most popular genres on Netflix

 Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
  
 Dataset
The dataset used in this project is the **Netflix Movies and TV Shows dataset**, sourced from Kaggle. It includes details such as title, type, director, cast, country, release year, rating, duration, genre, and description.

 Steps Performed
1. Data Collection from Kaggle  
2. Data Cleaning (handling missing values and duplicates)  
3. Exploratory Data Analysis (EDA)  
4. Data Visualization using charts  
5. Insight generation  

 Key Insights
- Netflix has more Movies compared to TV Shows  
- United States produces the highest amount of content  
- Content production increased significantly after 2015  
- Drama and International genres are the most popular  
- Majority of content is targeted towards mature audiences  

 Conclusion
The analysis reveals that Netflix focuses heavily on movies and international content. Over time, there has been a rapid increase in content production, reflecting Netflix's expansion and growing global audience.
